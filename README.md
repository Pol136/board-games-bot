# Telegram-бот для продажи настольных игр

Интеллектуальный Telegram-бот, который помогает пользователю выбрать настольную игру, отвечает на вопросы, обрабатывает голосовые сообщения и позволяет оформить заказ через WebApp-форму.

## Функции

* определение намерений пользователя с помощью ML;
* ответы по сценариям и корпусу диалогов;
* обработка текстовых и голосовых сообщений;
* оформление заказа через Telegram WebApp;
* сохранение заказов в CSV;
* просмотр и изменение статусов заказов;
* поиск информации через Wikipedia API.

## Стек

Python, Aiogram, scikit-learn, nltk, pymorphy2, SpeechRecognition, pydub / FFmpeg, Wikipedia API, HTML / JavaScript, CSV

## Запуск

Склонировать репозиторий:

```bash
git clone https://github.com/username/project-name.git
cd project-name
```

Создать и активировать виртуальное окружение:

```bash
python -m venv venv
venv\Scripts\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Создать файл `.env`:

```env
BOT_TOKEN=your_telegram_bot_token
ADMIN_ID=your_telegram_id
WEBAPP_URL=your_webapp_url
```

Запустить бота:

```bash
python bot.py
```

## Команды

| Команда      | Описание                             |
| ------------ | ------------------------------------ |
| `/start`     | запуск бота                          |
| `/help`      | справка                              |
| `/orders`    | просмотр заказов                     |
| `/setstatus` | смена статуса заказа администратором |

## Как работает бот

Пользователь отправляет сообщение. Бот очищает и лемматизирует текст, определяет интент с помощью модели машинного обучения и выбирает подходящий ответ. Если интент не распознан, используется поиск похожего вопроса в корпусе диалогов.

Голосовые сообщения конвертируются в текст и проходят ту же обработку.

Для оформления заказа используется WebApp-форма внутри Telegram. Данные заказа сохраняются в файл `orders.csv`.
